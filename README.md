📚 Habits — Трекер привычек с уведомлением в Telegram

Проект представляет собой backend-сервис на DRF для SPA-приложения. Позволяет пользователям формировать полезные привычки, отслеживать их выполнение и получать уведомления о новых целях прямо в Telegram.

🛠 Архитектура API
CRUD-операции: Реализованы через ModelViewSet (HabitCreateAPIView, HabitUpdateAPIView и др.).
Разделение представлений: Для публичных привычек используется отдельный эндпоинт HabitPublicListAPIView с правами доступа AllowAny.
Валидация бизнес-правил: Проверка на уровне представлений (perform_update) предотвращает создание циклических связей между привычками.
⚙️ Система прав доступа (RBAC)

Реализован строгий контроль данных:

Пользователь видит только свои привычки благодаря фильтрации в методе get_queryset.
Права доступа настраиваются динамически: изменение/просмотр/удаление доступно только владельцу привычки или модератору платформы.
🔄 Асинхронные задачи

Для отправки уведомлений при создании новой привычки настроена очередь задач на базе Celery + Redis. Это позволяет снять нагрузку с основного потока API и мгновенно информировать пользователя в Telegram.

🚢 Инфраструктура

Сервис заизолирован в Docker-контейнерах с помощью Docker Compose. В одном стеке развернуты приложение Python/Django, база данных PostgreSQL и брокер сообщений Redis.

🔧 Запуск проекта

Через Docker (рекомендуется)

Скопируйте переменные окружения из примера:
cp .env.example .env
Откройте .env и заполните секретные ключи (SECRET_KEY, REDIS_URL, TELEGRAM_BOT_TOKEN).

Запустите контейнеры:
docker-compose up --build

Документация Swagger будет доступна здесь: http://localhost/docs

Локальный запуск (с Poetry)

Установите Poetry, если он ещё не установлен: pip install poetry
Создайте виртуальное окружение и установите зависимости:
# Инициализация venv и установка зависимостей
poetry install

Примените миграции базы данных:
poetry run python manage.py migrate

Создайте суперюзера для админки:
poetry run python manage.py createsuperuser

Запустите сервер разработки:
poetry run python manage.py runserver

Документацию можно открыть тут: http://127.0.0.1:8000/docs
