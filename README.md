📅 Habits — Трекер привычек с Telegram-уведомлениями

Личный проект для отработки навыков проектирования REST API на Django/DRF, работы с асинхронными задачами Celery и интеграции внешних сервисов.

Основные функции
CRUD для управления привычками (CreateAPIView, UpdateAPIView и др.).
Изоляция данных: пользователь видит только свои привычки благодаря фильтрации в методе get_queryset.
Валидация бизнес-правил: запрет создания циклических связей между привычками (perform_update).
Асинхронная отправка уведомлений о создании новой привычки в Telegram через очередь задач (Celery + Redis).
Публичный каталог полезных привычек (AllowAny) с кастомной пагинацией для оптимизации мобильного трафика.
✨ Технологии (Стек)

Backend: Python 3.12+, Django 5.1+, Django REST Framework 3.15+
Базы данных: PostgreSQL, Redis
Асинхронность: Celery 5.4.0, eventlet
Инфраструктура: Docker, Docker Compose
Документация: Swagger (drf-yasg)
Инструменты: Poetry (pyproject.toml), Pytest (coverage)

Моя роль и архитектурные решения:
Проектирование архитектуры REST API на базе DRF (ModelViewSet).
Реализация системы прав доступа: аутентификация (IsAuthenticated), авторизация владельца (IsOwner) или публичного просмотра (AllowAny).
Бизнес‑логика: проверка целостности связанных сущностей (related_habit) при обновлении.
Настройка асинхронных задач (Celery Beat) для отправки уведомлений в Telegram.
Оптимизация вывода списка привычек пользователя (пагинация).

🔧 Запуск проекта

Через Docker (рекомендуется)

Скопируйте переменные окружения из примера:
cp .env.example .env
Откройте .env и заполните секретные ключи (SECRET_KEY, REDIS_URL, TELEGRAM_BOT_TOKEN).

Запустите контейнеры:
docker-compose up --build

Документация Swagger будет доступна здесь: http://localhost/docs

Локальный запуск (с Poetry)

Установите Poetry, если он ещё не установлен: pip install poetry
Создайте виртуальное окружение и установите зависимости:
Инициализация venv и установка зависимостей
poetry install

Примените миграции базы данных:
poetry run python manage.py migrate

Создайте суперюзера для админки:
poetry run python manage.py createsuperuser

Запустите сервер разработки:
poetry run python manage.py runserver

Документацию можно открыть тут: http://127.0.0.1:8000/docs
