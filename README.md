Проект «Привычки» — SPA для трекинга полезных привычек Контекст: Личный проект для отработки навыков проектирования REST API и работы с асинхронными задачами. Задача: Разработать отказоустойчивый бэкенд для SPA-приложения, обеспечив изоляцию данных пользователей, автоматизацию уведомлений и публичный каталог привычек.

Технический стек:

Язык и фреймворк: Python 3.12, Django 5.1.4, Django REST Framework 3.15.2
Базы данных: PostgreSQL
Асинхронность и кеш: Celery 5.4.0, Redis 5.2.1
Инфраструктура: Docker

Моя роль и архитектурные решения:

Проектирование API: Спроектировал архитектуру REST API для CRUD-операций. Реализовал разграничение прав доступа (IsAuthenticated, кастомный IsOwner), гарантируя, что пользователь работает только со своими данными.
Бизнес-логика: Внедрил валидацию на уровне представлений (DRF perform_update), запретив создание циклических ссылок между привычками.
Асинхронность: Настроил очередь задач на Celery + Redis для отправки уведомлений в Telegram, чтобы снять нагрузку с основного потока API.
Публичный API: Реализовал эндпоинт для просмотра открытых привычек (AllowAny) с кастомной пагинацией для оптимизации мобильного трафика.
Инфраструктура: Заизолировал приложение, базу данных и брокер сообщений в Docker-контейнерах.
